# HTML Advanced - Webpage Implementation from Designer File

## Project Overview
This project focuses on building a structured, semantically rich webpage entirely from scratch based on a professional designer specification (Figma). Unlike previous basic projects, this phase emphasizes strict adherence to proper HTML5 semantics, document architecture, and layout blueprint interpretation without relying on CSS styling.

## Objectives
* Interpret and translate a designer layout (Figma wireframes) into clean, valid HTML5 code.
* Utilize advanced semantic HTML elements (such as `<header>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>`) to construct an accessible and logical document structure.
* Organize project assets and documentation effectively within a structured repository.
* Ensure code validity and compliance with W3C web standards.

## Resources & Assets
* **Design File:** Access the official design layout via the provided Figma link/file to inspect typography, spacing, component hierarchy, and layout structures.
* **Fonts:** Required typefaces include *Source Sans Pro* and *Spin-Cycle-OT* (referenced as specified in the design guidelines).
